# Game Squad Arena Bot

Bot oficial de Discord para gestionar torneos, asignar roles, crear canales, y controlar estadísticas de jugadores en Game Squad Arena.

## Características principales
- Asignación automática de roles por colores y por Riot Games.
- Gestión de torneos 1vs1, 3vs3, y 5vs5.
- Comprobación de resultados mediante capturas de pantalla.
- Creación de canales personalizados y organización épica.
- Sistema de monedero virtual para premios.
- Soporte de comandos en español.

## Cómo ejecutarlo localmente
```bash
npm install
npm start
```

## Requisitos
- Node.js >= 18
- Token válido de Discord en variable de entorno `DISCORD_TOKEN`
- Acceso a una base de datos SQLite.
